VERSÃO 0.1 · ACESSO ANTECIPADO

Seu Atlas, no Mac.

Baixe o pacote ZIP da primeira versão do aplicativo e siga os passos para abrir e adicionar ao Dock.

Baixar aplicativo · v0.1 ZIP
  1. Baixe e descompacte.

    Dê dois cliques no arquivo atlas-0.1.0.zip. Você verá a pasta atlas-0.1.0. Se o Safari já descompactou o arquivo, use essa pasta.

  2. Abra o Terminal.

    Pressione ⌘ + Espaço, digite Terminal e pressione Enter.

  3. Selecione a pasta.

    Digite cd , com um espaço depois, e arraste a pasta atlas-0.1.0 para dentro do Terminal. Pressione Enter.

  4. Inicie o Atlas.

    Cole o comando abaixo e pressione Enter:

    python3 -m http.server 8000 --bind 127.0.0.1

    Se o comando não estiver disponível, instale o Python para macOS, abra novamente o Terminal e repita os dois últimos passos.

  5. Abra no navegador.

    Acesse http://127.0.0.1:8000 no Safari ou Chrome.

  6. Adicione ao Dock.

    No Safari do macOS Sonoma 14 ou posterior, escolha Arquivo → Adicionar ao Dock → Adicionar. No Chrome, clique em Instalar app dentro do Atlas e siga as instruções do navegador.

Enquanto usa esta versão local, mantenha o Terminal aberto.

Depois de reiniciar o Mac, selecione a pasta e execute o comando novamente. Para encerrar, pressione Control + C no Terminal.

O ZIP contém uma aplicação web. Abrir o arquivo index.html diretamente pelo Finder não inicia o aplicativo.

A cópia local tem armazenamento separado do site. Para acessar memórias já sincronizadas, entre na mesma conta. Faça backups pelo botão Exportar.
